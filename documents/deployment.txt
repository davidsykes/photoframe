 python utilities/build_app_release.py version

Transfer the app release to the new system
 scp releases/photoframe-0.1.0.zip pi@192.168.1.nnn:/home/pi/photoframe

Log on to the new system
 ssh

Unzip the code
 unzip -o 


Edit  release/start-photoframe.sh

 chmod +x start-photoframe.sh

Add the sh file to the autostart
 nano ~/.config/labwc/autostart
and add
 /home/pi/photoframe/start-photoframe.sh &

and edit the values
