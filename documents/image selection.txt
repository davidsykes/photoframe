The photos are organised into photo sets.
Each photo set is given a date, representing the day it is added to the frame.
Each set is given a randomisation weighting, controlling how often it gets picked for viewing

For example:

Age of set    Weight
first 7 days  8
1–4 weeks     5
1–3 months    3
older         1

def get_weight(age_days):
    if age_days < 7:
        return 8

    if age_days < 30:
        return 5

    if age_days < 90:
        return 3

    return 1


Selecting an image:
A random set is chosen, then a random photo from that set.
If that photo has been shown in the last 50 photos another is chosen
The check is repeated up to 100 times, if it fails on the 100th time the repeated photo is shown
